# Core User Stories

### Install Agent Trail

As a repository owner, I can install the Agent Trail GitHub App on selected repositories.

### Delegate an issue

As a developer, I can comment `/agent-trail run` on an issue to create an agent task.

### Monitor a task

As a developer, I can see:

- Task status
- Current phase
- Agent plan
- Commands
- Command output
- Files changed
- Validation results
- Runtime
- Resource use

### Cancel a task

As a developer, I can cancel a running task and preserve logs.

### Review evidence

As a reviewer, I can inspect:

- Original instructions
- Agent plan
- Summary of changes
- Verified tests
- Failed tests
- Denied actions
- Risks
- Unverified assumptions

### Request revisions

As a reviewer, I can leave pull-request feedback and ask Agent Trail to run a follow-up attempt.

### Clean up resources

As an administrator, I can configure how long completed workspaces and logs are retained.
