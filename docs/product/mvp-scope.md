# MVP Scope and Non-Goals

## MVP Scope

The MVP should include:

- GitHub App installation
- Repository synchronization
- GitHub webhook validation
- `/agent-trail run` issue command
- Durable task storage
- Task queue
- One agent provider
- One isolated Linux workspace per task
- Git branch and worktree creation
- Agent activity timeline
- Command and log capture
- Runtime timeout
- Cancellation
- Trusted validation commands
- Git commit and branch push
- Draft pull-request creation
- GitHub Check integration
- Structured evidence report
- Basic web dashboard
- Automatic workspace cleanup
- Docker Compose development environment
- Production-style Kubernetes deployment
- Unit, integration, and end-to-end tests


## Explicit Non-Goals

Do not include in the first release:

- Git repository hosting
- SSH Git transport
- A GitHub-style source browser
- Automatic merging
- Windows runners
- macOS runners
- Billing
- GitHub Marketplace launch
- A custom coding model
- Full semantic code search
- Arbitrary workflow YAML
- General CI/CD pipelines
- Fully hostile multi-tenant execution
- IDE plugins
- Mobile applications
- Advanced multi-agent planning
